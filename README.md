# Fermor — Frontend Developer Assignment

A polished, responsive concept homepage for Fermor, a financial clarity/planning product.

## Stack
- React
- Vite
- CSS
- Lucide React icons

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Design decisions

- Designed a calm fintech visual language with warm off-white surfaces, dark green accents and generous whitespace.
- The hero communicates Fermor's core value immediately: understanding and acting on your money with less noise.
- Added a working interactive product dashboard with tabs for Overview, Spending and Goals.
- Added expandable FAQ items and responsive mobile navigation to demonstrate working implementation rather than a static mockup.
- The dashboard is intentionally illustrative and does not represent real financial data or a real financial service.

## Assignment note

This is an original frontend interpretation created for the Fermor frontend assignment. It is not the official Fermor product or website.
